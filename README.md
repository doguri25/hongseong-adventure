# 도착 대화창 모바일 수정 · v1.3.4

# 모바일 화면 개선 · v1.3.3

휴대폰에서는 **오늘의 첫 탐방 → 펼치기 / 접기**로 자세한 미션을 확인합니다. 접혀 있어도 현재 목표 장소는 보입니다. 주소, 전체 지도, 주변 찾기는 지도 위가 아닌 별도 안내 줄에 표시됩니다.

이동 수단·이동 모드는 상단 **이동 ▾**에서 선택합니다. 지도는 펼쳐진 안내 아래에서 별도 크기를 가지므로 조이스틱을 덮지 않습니다. 휴대폰을 회전하면 자동으로 세로 / 가로 배치가 적용됩니다.

기존 탐방 데이터는 동일한 웹 주소에서 업데이트할 때 유지됩니다. 다른 주소로 배포하면 브라우저 저장소가 달라지므로 기존 설정에서 이어하기 파일을 내보내고 가져오세요.

실행: `dist` 폴더를 정적 웹 서버에 배포합니다. ZIP 미리보기나 `file://` 직접 열기는 모듈·지도 JSON 불러오기를 제한할 수 있습니다. 로컬에서는 `python -m http.server 8000 --directory dist` 실행 후 브라우저로 localhost:8000에 접속합니다.

검사: `npm test` (외부 패키지 설치 없이 Node.js 내장 테스트 사용).

전체 소스 배포본은 글꼴 파일을 포함하지 않고 기기에 설치된 글꼴을 사용합니다. 기존 폰트·자산을 그대로 유지하려면 수정파일 ZIP을 기존 프로젝트에 적용하세요.

## 성능과 실행

`dist`를 정적 웹으로 제공한다. 외부 지도 API 키나 실행 중 지오코딩 요청이 필요 없다. 배경은 확대율·기기 해상도에 따라 지리 범위가 달라지는 516픽셀 타일로 공간 인덱스를 이용해 그리며 최대 64개를 캐시한다. 축소된 이미지를 확대에 재사용하지 않는다. 미니맵만 별도의 전체 배경을 사용한다. 기본 길 모드는 공개 도로·산책로의 양방향 연결 그래프에서 A*로 이동한다. 자유 모드만 목표까지 직선으로 이동한다. 군 전체를 거대한 고해상도 캔버스 한 장으로 만들지 않는다.

`scripts/prepare_county.py SOURCE_DIR OUTPUT_DIR`는 공개 OSM 응답 `features.json`, `places.json`, SGIS 가공 경계 `admin-source.geojson`에서 지도를 만든다. `prepare_facilities.py`는 그 결과와 정확한 학교 조회 응답 `school-verified.json`을 사용한다. 문화 데이터는 `scripts/prepare_culture.py SOURCE_DIR OUTPUT_DIR`로 생성하며, 공개 OSM 응답 및 코드에 명시된 검토 좌표·출처를 사용한다. 지도 재생성에는 Python Pillow·NumPy·Shapely가 필요하다. 실제 게임 실행은 별도 의존성 설치가 필요 없다.

## 검증과 남은 범위

`node --test tests/*.test.js`: 47개 핵심 검사 통과. 비행기의 모든 지도 목적지 직선 이동, 축소·확대 반복 때 타일 해상도 및 화면 덮임, 실제 읍면 판정, 모든 장소의 사방 접근, 자동 안내 재진입·고속 통과, 해안·섬, 저장 변환, 보상, 업종 아이콘과 이름 마스킹, 이전 학교, 정적 에셋을 확인했다. 218개 지도 표지의 읍면 판정과 표시 주소가 모두 일치한다. JavaScript 문법·정적 모듈/에셋 참조 검사 완료. 브라우저 렌더링·갤럭시 태블릿 실기기 테스트는 수행하지 않았다.

아이스크림 3학년 1학기 1단원 연계 목적의 새 설명과 문항이며, 정확한 판본·차시·쪽수 및 종이 홍성 지역화 교재와의 대조는 아직 완료하지 않았다. 학생 QR 배포 시 사이트의 열람 권한 설정이 필요하다.

- 기본 글꼴을 자체 제공하는 나눔스퀘어라운드로 바꾸었다. 본문18px, 설명21px, 주요 버튼17px이다. 글꼴 출처 NAVER 한글한글 아름답게, SIL OFL1.1은 `dist/assets/NANUM-LICENSE.txt`에 포함한다.
- Web Audio로 버튼·이동·발견·정답·재도전·금화 효과음과 작은 발소리를 만든다. 사용자 첫 입력 후 소리를 활성화하며 효과음 켜짐·음량60%, 배경음 꺼짐이 초기값이다. 기존 저장의 음소거 선택은 보존한다. 배경음과 읽기가 겹치지 않도록 읽는 동안 배경음을 줄인다.
- TTS는 일반 웹의 Web Speech API로 현재 브라우저가 제공하는 Google 한국어 음성을 우선 선택한다. 늦게 도착한 음성 목록을 갱신하며 설명 닫기·변경 시 취소한다. Google 한국어가 없으면 기기의 한국어 음성을 사용하고 현재 선택을 표시한다. Google 음성이 모든 Chrome/Android 기기에 제공되는 것은 아니며 Windows 음성 사용을 완전히 금지하거나 외부 유료 TTS에 의존하지 않는다.
- `길로만 다니기 / 길 무시하기` 토글은 클릭 이동과 조이스틱에 모두 적용된다. 길 모드는 도로·산책로를 따라가며 일방통행은 무시한다. 끊긴 도로망 사이로 길을 만들지 않는다. 건물 가까운 길(최대350m)에서 안내가 열릴 수 있고, 길이 없는 섬 등은 자유 모드를 안내한다. 실제 보행 길안내 기능이 아니다.
- 코드·콘텐츠 검사에서 양방향 길찾기, 조이스틱 회전, 모드 전환, 단절된 섬, 실제 내포→홍성읍·광천·남당항 경로, Google 우선 선택, 지연 음성 취소, 41개교/12개 관공서 자료, 지도 확대·저장·보상을 확인했다. 갤럭시 태블릿의 실제 소리·성능·화면 검증은 하지 않았다.


## 1.0.0 탐험 기능 업데이트

현재 화면 버전의 단일 기준은 `dist/release.js`의 RELEASE이다. 사용자 요청에 따라 앞으로도 기능 추가는 minor, 버그 수정은 patch를 올리고 화면의 최근 변경점과 CHANGELOG.md를 함께 갱신한다. package.json도 같은 버전을 유지한다. 사이트 열람 권한은 버전 번호와 별도이며 요청 없이 공개로 바꾸지 않는다.

이동 수단은 걷기 ×1·자전거 ×2·자동차 ×4·슈퍼카 ×8이다. 기존 저장의 fast/faster 값은 각각 자동차/슈퍼카로 유지한다. SpriteAtlas가 이미지 생성 도구로 만든 14개 원본 그림의 색상 키를 투명 처리해 지도에 그린다. 원본 RGB 파일을 보존하며 차량·인물·소품마다 지정한 사각형을 사용한다. 실제 지형 도형은 변경하지 않고 녹지 안의 430개 장식과 14개 가상 NPC를 추가했다.

랜덤 미션은 한국 날짜와 기기별 상태로 저장된다. 처음은 가까운 장소 위주이며 길 모드에서는 실제 연결 그래프에서 접근 가능한 지점으로 제한한다. 다른 장소 안내를 열면 직행 조건이 끝나고 목표에 도착하면 미션 완료만 기록한다. 다른 미션으로 출발하면 새 출발로 처리하되 이미 목표 근처인 경우 보너스는 없다. NPC 도움과 이야기 페이지/사진 자료 열람은 들름으로 세지 않는다. 같은 장소의 직행 보너스는 하루 한 번 50금화이며 기존 장소·퀴즈 보상과 별도로 장부에 남긴다.

`release.css`와 `layout.js`에서 가로/세로 방향과 visualViewport 높이를 반영한다. 일반 팝업은 고정 높이의 CSS 다단 흐름을 이전/다음 쪽으로 표시하며, 입력/클릭 이벤트가 연결된 노드를 유지한다. 장소 팝업은 사진·이야기를 좌우 또는 상하로 배치하고 출처/학교 추가 자료는 별도 페이지에서 연다. 아주 낮은 세로 화면에서는 사진을 접어 이야기 공간을 확보한다.

40개 핵심 검사에 랜덤·일일 갱신·보상 지속·중복 방지·키보드 메뉴 전환·NPC 범위·스프라이트 참조 검사가 포함된다. 정적 구문/파일 참조를 확인했으며 브라우저 화면·실제 갤럭시 태블릿의 소리/스크롤/회전 검증은 하지 않았다. 정식 배포 전 실기기 검증이 남아 있다. 자세한 최근 변경점은 CHANGELOG.md와 제목을 눌러 여는 정보 화면에 있다.
